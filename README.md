# First PR Demo

This is a sample repository to practise making pull requests.

## How to contribute

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Open a pull request

## About

This project demonstrates the basics of GitHub workflow.

## Glossary

- **Repository:** A project folder tracked by Git. It holds all the files and their complete change history.
- **Commit:** A saved snapshot of changes, with a short message describing what changed and why.
- **Branch:** A separate line of work. You can make changes on it without affecting the `main` branch.
- **Pull request:** A request to merge the changes from one branch into another. Others can review and discuss the changes before they are accepted.
- **Merge:** Combining the changes from one branch into another, for example when a pull request is accepted.
- **Issue:** A place to track a task, bug or idea. Pull requests can reference issues and close them automatically.
